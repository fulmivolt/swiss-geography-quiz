# Swiss Geography Quiz

Play: https://fulmivolt.github.io/swiss-geography-quiz/

Interactive Swiss geography quiz for desktop, tablet and phone browsers. German and English interface. Eleven modes, three difficulty levels, map or written answers. Rivers and lakes can be played together or separately.

Everything combines all 155 atomic questions. The Swiss profile provides 17 reveal cards, and the landscape mode teaches Jura (10%), Swiss Plateau (30%) and Alps (60%) with difficulty-based map interaction.

Before the cities quiz starts, choose between the 22 non-capital localities or a 48-question session that also includes all 26 cantonal capitals.

GitHub Pages serves this static website from the main branch, root folder. No backend, paid server or installation required.

Geography: swissBOUNDARIES3D 2026 and swissTLMRegio 2025, © swisstopo; Landscape Typology Switzerland, © Federal Office for Spatial Development ARE. Optional background: © OpenStreetMap contributors. Map rendering: Leaflet 1.9.4.

The website files are exported from the development project's dist directory with scripts/export-pages.mjs. Filenames are flattened for browser upload; quiz behaviour and data are preserved.
